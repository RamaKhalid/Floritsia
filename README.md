# 🌱 Floritsia

Floritsia is a simple **plant e-commerce website** where users can browse and purchase plants online.

## ✨ Features

* 🌿 Browse plants and products
* 🔎 Search and filter products
* 🛒 Add products to a shopping cart
* 📦 View orders and order details
* 👤 Customer account management
* 🔐 Admin login
* ⚙️ Admin product management
* ➕ Add, update, and delete products
* 🗄️ MySQL database

## 🛠️ Built With

* PHP
* JavaScript
* HTML
* CSS
* MySQL

## 📚 About

This project was developed to practice **web development, PHP, database integration, and e-commerce functionality**.

## 🚀 How to Run

1. Clone the repository.
2. Set up a local PHP server using **XAMPP** or a similar environment.
3. Import `floritsia.sql` into MySQL.
4. Place the project inside the server's web directory.
5. Open the project in your browser.
